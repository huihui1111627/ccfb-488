定时调度

支持 */N、逗号列表、区间、星号。例： */30 * * * * 每半小时； 0 9 * * 1-5 工作日早9点。到点自动跑增量，引擎忙时自动跳过。

Mock 平台故障注入（演示自动退避 / 续登 / 重试）

采集端行为：429 读取 Retry-After 退避；500 按 2/5/10/20 秒指数退避； auth 平台 401 自动重新走 Playwright 登录续会话；单条最终失败进入重试队列。

Mock 数据演化（演示两轮增量）

每轮演化会新增公告（含跨平台转载）并发更正公告。流程：演化第1轮 → 跑增量 → 演化第2轮 → 再跑增量，到「变更记录」看预算/截止时间差异，重复条目不会二次入库。
